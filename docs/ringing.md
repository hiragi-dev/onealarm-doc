# アラームが鳴ったら

このアプリの本番です。実際に何が起きるかを、鳴る前に読んでおいてください。

## 起きること

設定した時刻になると、**離れた場所に置いた機器が音を鳴らし始めます。**
同時に、スマホの画面が**全部**この停止画面に切り替わります。

![鳴動中の画面](/screenshots/ringing.png)

他のタブには移れません。設定も見られません。
**鳴っている間、アプリはこの画面しかありません。**

## 画面に出るもの

### 歩行中 / 静止中

上の大きな表示です。スマホのセンサーが**いま歩いているかどうか**を見ています。

- **歩行中** … 緑色になり、波紋が広がります。**歩いている間は音が一時停止します**
- **静止中** … 灰色に戻り、**音がまた鳴り始めます**

![歩行中の表示](/screenshots/ringing-walking.png)

移動中ずっと鳴り続けることはありません。ただし止まっているのは歩いている間だけで、
立ち止まればまた鳴ります。

### 歩行検知オフ

「歩行検知を有効にする地点」を設定したアラームでは、鳴り始めたときの表示が
**錠のマークと「歩行検知オフ」**になります。

![歩行検知オフの表示](/screenshots/ringing-locked.png)

この間は、**スマホを動かしても音は一時停止しません。**
下のチップに、**どこまで行けば歩行検知が有効になるか**と、そこまでの距離が出ています。

その地点に着くと「歩行検知を有効にしました」と通知が出て、表示が「歩行中 / 静止中」に変わります。
一度有効になれば、その地点を離れても鳴り止むまでは有効のままです
（→ [歩行検知を有効にする地点](/screens#歩行検知を有効にする地点)）。

### あと何メートルか

その下のカードに、**停止地点の名前**と、そこまで**残り何メートルか**が出ます。

近づくほど数字が減っていきます。数字が減らないときは、**方向が違います。**

数字の下の小さな地図には、**停止地点（ピン）と今いる場所（青い点）**が点線で結ばれて出ます。
どちらへ向かえばいいか迷ったら、この地図を見てください。
この地図は動かせません。

::: info 「現在地を取得しています…」と出るとき
GPSが最初の位置を測るのに数秒〜十数秒かかることがあります。そのまま歩き始めて構いません。
:::

### 到達しました

円の中に入ると **「停止地点に到達しました。まもなく自動的に停止します」** と表示され、音が止まります。

ボタンを押す必要はありません。着けば止まります。

## 止めるボタンはありません

画面を隅々まで探しても、**アラームを止めるボタンはありません。**
実装し忘れているのではなく、**意図的に用意していません。**

「今日は特別だから」と押せるボタンが1つでもあると、そのボタンは必ず押されます。
そして二度寝します。このアプリはそれを防ぐために作られているので、
**逃げ道になるものを一切置かない**という方針を取っています。

同じ理由で、鳴っている間は次のこともできません。

- 鳴っているアラームを**変更・削除・オフにする**
- 停止方法の**場所を書き換える**（今いる場所にずらして止める、を防ぐため）

## よくある状況

### 歩いているのに「静止中」のまま

スマホを**手に持つかポケットに入れて**歩いてください。
机の上に置いたままだとセンサーが反応しません。

なお、「静止中」のままでも困ることはありません。歩行中に音が止まるのは**一時的**なもので、
**アラームが完全に止まる条件は、あくまで停止地点に着くこと**だからです。

### 「歩行検知オフ」のまま変わらない

チップに書かれている地点まで、まだ着いていません。
そこに着くまでは、歩いても音は一時停止しません。**先にその地点へ向かってください。**

### 距離が減らない / 到着しているのに止まらない

- 建物の中や地下ではGPSが弱くなります。**いったん外に出て**ください
- 半径が狭すぎる可能性があります。次回のために [半径を広げて](/getting-started#半径はどのくらいがいいですか) ください
- 位置情報の許可が切れていないか確認してください（→ [よくある質問](/faq)）

### 「停止方法が設定されていない」と表示された

そのアラームには止める場所が決まっていないため、着いても自動で止まりません。
鳴り止んだあと、「アラーム」タブでそのアラームを開き、停止方法を設定してください。

### 通信が切れていると表示された

機器との通信が切れていても、**機器は自分で鳴り続けます。**
止めるにはやはり停止地点まで行く必要があります。
