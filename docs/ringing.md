# 鳴動中の画面

実際に鳴ったときに何が起きるかを、鳴る前に一度読んでおいてください。寝起きに初見で理解するのはかなり厳しいと思います。

## 鳴り始めたときの動き

設定した時刻になると、離れた場所に置いた機器が音を鳴らし始めます。同時に、スマホの画面が丸ごとこの停止画面に切り替わります。

![鳴動中の画面](/screenshots/ringing.png)

他のタブには移れませんし、設定も見られません。鳴っている間、アプリにはこの画面しかありません。

## 画面の見方

### 歩行中 / 静止中 {#walking}

上の大きな表示です。スマホのセンサーでいま歩いているかどうかを見ていて、歩行中は緑色になって波紋が広がり、静止中は灰色になります。
歩いている間は音が一時停止するので、移動中ずっと鳴り続けることはありません。ただ、止まっているのは歩いている間だけで、立ち止まればまた鳴ります。

![歩行中の表示](/screenshots/ringing-walking.png)

### 歩行検知オフ

「歩行検知を有効にする地点」を設定したアラームでは、鳴り始めたときの表示が錠のマークと「歩行検知オフ」になります。

![歩行検知オフの表示](/screenshots/ringing-locked.png)

この間はスマホを動かしても音は一時停止しません。下のチップにどこまで行けば歩行検知が有効になるかと、そこまでの距離が出ているので、まずはそこへ向かってください。
着くと「歩行検知を有効にしました」という通知が出て、表示が「歩行中 / 静止中」に変わります。一度有効になれば、その地点を離れても鳴り止むまでは有効のままです。設定の意味については[画面の使い方](/screens#walk-unlock-point)をご覧ください。

### 停止地点までの距離

その下のカードには、停止地点の名前と、そこまで残り何メートルかが出ます。近づくほど数字が減っていくので、減らないときは方向が違います。

数字の下の小さな地図には、停止地点(ピン)と今いる場所(青い点)が点線で結ばれて表示されます。どっちに向かえばいいか迷ったらこちらを見てください。この地図は動かせません。

「現在地を取得しています…」と出ている間は、GPSが最初の位置を測っているところです。数秒~十数秒かかることがありますが、そのまま歩き始めて構いません。

### 到達時の動き

円の中に入ると「停止地点に到達しました。まもなく自動的に停止します」と表示され、音が止まります。ボタンを押す必要はなく、着けば止まります。

## 止めるボタンについて

画面を探しても、アラームを止めるボタンはありません。実装し忘れたわけではなく、付けないことにしています。

「今日は特別だから」と押せるボタンが1つでもあると、そのボタンは必ず押されて二度寝することになります。このアプリはそれを防ぐために作っているので、逃げ道になるものは置かない、というスタンスです。

同じ理由で、鳴っている間は鳴っているアラームの変更・削除・オフと、停止方法の場所の書き換えもできないようになっています(今いる場所に停止地点をずらして止める、というやつを防ぐためです)。

## よくある状況

### 歩いても「静止中」のままの場合

スマホを手に持つかポケットに入れて歩いてください。机の上に置いたままだとセンサーが反応しません。
なお、「静止中」のままでも致命的ではありません。歩行中に音が止まるのはあくまで一時的なもので、アラームが完全に止まる条件は停止地点に着くことだからです。

### 「歩行検知オフ」のままの場合

チップに書かれている地点にまだ着いていません。そこに着くまでは歩いても音は一時停止しないので、先にその地点へ向かってください。

### 距離が減らない・到着しても止まらない場合

建物の中や地下ではGPSが弱くなるので、いったん外に出てみてください。それでも止まらないなら半径が狭すぎる可能性があるので、次回のために[半径を広げて](/getting-started#radius)おくことをおすすめします。位置情報の許可が切れていないかも確認してみてください([よくある質問](/faq)にまとめています)。

### 通信が切れたと表示された場合

機器との通信が切れていても機器は自分で鳴り続けるので、止めるにはやはり停止地点まで行く必要があります。
