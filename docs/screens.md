# 画面の使い方

画面の下に3つのタブがあります。使う画面はこれだけです。

| タブ | 何をする画面か |
| --- | --- |
| **設定** | 音を鳴らす機器とつなぐ |
| **アラーム** | 何時に鳴らすかを決める |
| **停止** | どこまで歩けば止まるかを決める |

## アラーム

![アラーム一覧](/screenshots/alarm-list.png)

登録したアラームが時刻順に並びます。

### 一覧の見方

大きい数字が**鳴る時刻**、その下の小さい文字が設定の要約です。

> **平日 ・ 会社 ・ NFC**

左から順に、**繰り返す曜日**、**止めるために行く場所**、**NFC認証の有無**です。
曜日は「平日」「週末」「毎日」とまとめて表示され、それ以外は「月 水 金」のように並びます。
薄く表示されている行は、いまオフになっているアラームです。

### 操作

- **行をタップ** … 編集画面が開きます。時刻・曜日・停止方法・NFCを変えられます
- **右のスイッチ** … オン / オフの切り替え
- **右上の ＋** … 新しいアラームを追加

編集画面の一番下に **「このアラームを削除」** があります。

### NFC認証について

オンにすると、**場所に着いただけでは止まりません**。
そこに貼っておいたNFCタグにスマホをタッチして、はじめて止まります。

「到着したことにして引き返す」ができなくなるので、より強力です。使わなくても構いません。

## 停止

![停止方法の一覧](/screenshots/stop-methods.png)

**停止方法**（＝止めるために行く場所）を管理する画面です。

カードには地図のプレビューと、名前・到達判定の半径が出ます。

- **カードをタップ** … 地図が大きく開きます。そこから場所や半径を変更できます
- **ゴミ箱アイコン** … 削除
- **右上の「追加」** … 新しい場所を登録

### 「使用中」バッジ

いずれかのアラームで使われている停止方法には **「使用中」** と表示され、**削除できません**。

消してしまうと、そのアラームを止める手段が無くなってしまうためです。
どうしても消したいときは、先にそのアラームの停止方法を別のものに変えてください。

::: info 鳴っているときは
アラームが鳴っている間、この画面は表示されません。
鳴り始めた瞬間に、画面全体が停止画面に切り替わります（→ [アラームが鳴ったら](/ringing)）。
:::

## 設定

![設定画面](/screenshots/settings.png)

**音を鳴らす機器とつなぐための画面**です。ふだんは触りません。

一番上にある図が、いまの接続状態を表しています。

```
[ アプリ ] ── [ ブローカー ] ── [ 機器 ]
```

**ブローカー**は、アプリと機器の間で連絡を中継する仕組みだと考えてください。
線と丸の色が緑になっていれば、正常につながっています。

入力する項目（接続先のアドレス、ユーザー名、パスワード、機器のID）は、
**機器をお渡しするときにこちらからお伝えします。**
その値をそのまま入れて「接続」を押してください。自分で考える必要はありません。

機器側の準備がまだのときは [機器のセットアップ](/device-setup) を先に済ませてください。

::: danger つながっていないとき
アラームの追加・変更ができず、一覧が暗く覆われます。
このときは [よくある質問](/faq#つながらない) を確認してください。
:::
