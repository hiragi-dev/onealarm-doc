# 画面の使い方

画面の下に3つのタブがある。使う画面はこれだけ。

- 設定 … 音を鳴らす機器とつなぐ
- アラーム … 何時に鳴らすかを決める
- 停止 … どこまで歩けば止まるかを決める

## アラーム

![アラーム一覧](/screenshots/alarm-list.png)

登録したアラームが時刻順に並ぶ画面。大きい数字が鳴る時刻で、その下に繰り返す曜日が出る。曜日は「平日」「週末」「毎日」のようにまとめて表示され、それ以外の組み合わせは「月 水 金」のように並ぶ。

その下にあるチップは、そのアラームがどうやって止まるかを表している。

- 青いチップ … 止めるために行く場所、つまり停止方法の名前
- 緑のチップ … 歩行検知を有効にする地点の名前。この場所に着くまで歩行検知が働かない。詳しくは[後の節](#walk-unlock-point)で説明する
- 「停止方法未設定」の黄色いチップ … 止める場所が決まっていない。このままだと鳴っても自動で止まらないため、編集して設定する

薄く表示されている行は、オフになっているアラーム。

行をタップすると編集画面が開き、右のスイッチでオンとオフを切り替えられる。新しく追加するときは右上の＋から。手順は[はじめかた](/getting-started#step-3)に書いている。

### 編集画面

![アラームの編集画面](/screenshots/alarm-edit.png)

上から順に、時刻、繰り返す曜日、停止方法、歩行検知を有効にする地点を変えられる。停止方法を選ぶと、その場所が地図で表示される。

変更したら右上の「保存」を押す。左上の矢印で戻ると変更は破棄される。削除は一番下の「このアラームを削除」から。

なお、鳴っている最中のアラームは変更も削除もできない。開いても変更できない旨が表示されるだけなので、停止地点まで移動して止めてから操作する。

### 歩行検知を有効にする地点 {#walk-unlock-point}

アラームが鳴っている間は、歩いていると音が一時停止する。詳しくは[鳴動中の画面](/ringing#walking)に書いているが、一度歩き出せばあとは停止地点まで持っていくだけで済むようにするための機能である。ただ、この歩行検知はスマホの動きを見ているだけなので、布団の中でスマホを振っても歩いていることにできてしまう。

「歩行検知を有効にする地点」は、この抜け道を塞ぐための設定。設定しておくと、鳴り始めてからその地点に着くまでは歩行検知が働かず、どれだけスマホを動かしても音は一時停止しない。着いた時点で歩行検知がオンになり、そこから停止地点までは歩いている間だけ音が止まる、という流れになる。

地点は登録済みの停止方法の中から選ぶため、使いたい場所がまだ無ければ先に「停止」タブで登録しておく。場所は、玄関やトイレのように起き上がらないと行けないところが向いている。枕元では意味がない。

設定しなくても構わない。「最初から有効」のままにしておくと、鳴り始めた時点から歩行検知が働く。

なお、この地点に着いてもアラーム自体は止まらない。歩行検知が始まるだけで、アラームが完全に止まるのはあくまで停止方法の地点に着いたときである。そのため、この地点と停止方法に同じ場所は選べない。

## 停止

![停止方法の一覧](/screenshots/stop-methods.png)

停止方法、つまり止めるために行く場所を管理する画面。1行が1つの場所で、地図の小さなプレビュー、名前、到達判定の半径が並ぶ。その下のチップはその場所を使っているアラームの時刻で、どのアラームにも使われていなければ「未使用」と出る。

行をタップすると地図が大きく開き、右下の「編集」から場所や半径、名前を変更できる。削除は右端のゴミ箱から。新しい場所を登録するときは右上の「追加」を押す。手順は[はじめかた](/getting-started#step-2)に書いている。

![登録した場所を地図で確認する](/screenshots/stop-method-view.png)

### 使用中の場所の削除

いずれかのアラームで使われている場所は、ゴミ箱が押せない。停止方法として使われている場合も、歩行検知を有効にする地点として使われている場合も同じ。
消してしまうとそのアラームを止める手段が無くなるため、どうしても消したいときは先にそのアラームの設定を別の場所に変える。

また、アラームが鳴っている間はこの画面は表示されず、鳴り始めた瞬間に画面全体が停止画面に切り替わる。こちらは[鳴動中の画面](/ringing)で説明する。

## 設定 {#settings}

![設定画面](/screenshots/settings.png)

音を鳴らす機器とつなぐための画面で、ふだんは触らない。

### 接続状態

一番上の図が、現在の接続状態を表している。

```
[ アプリ ] ── [ ブローカー ] ── [ エッジ ]
```

エッジが音を鳴らす機器で、ブローカーはアプリと機器の間で連絡を中継するサーバーのようなもの。線の下のチップが「接続済み」「オンライン」と緑で出ていれば正常につながっている。その下の「接続」「切断」のボタンで、接続と切断ができる。

### ブローカー / エッジデバイス

URL、ユーザー名、パスワード、デバイスIDを入力する欄。ここに入れる値は機器の配布時に案内するので、その値をそのまま入れて「接続」を押す。自分で考える必要はない。

つながっている間はこれらの欄を書き換えられず、触ると「接続中は設定を変更できません」と出る。変更したいときは先に「切断」を押してから書き換え、もう一度「接続」する。

機器側の準備がまだのときは[機器のセットアップ](/device-setup)を先に済ませる。また、つながっていない状態ではアラームの追加や変更ができず、一覧が暗く覆われる。そのときは[よくある質問](/faq#connection)を参照。
