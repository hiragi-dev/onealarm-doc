# 画面の使い方

画面の下に3つのタブがあります。使う画面はこれだけです。

| タブ | 何をする画面か |
| --- | --- |
| **設定** | 音を鳴らす機器とつなぐ |
| **アラーム** | 何時に鳴らすかを決める |
| **停止** | どこまで歩けば止まるかを決める |

## アラーム

![アラーム一覧](/screenshots/alarm-list.png)

登録したアラームが時刻順に並びます。

### 一覧の見方

大きい数字が**鳴る時刻**、その下の小さい文字が**繰り返す曜日**です。
曜日は「平日」「週末」「毎日」とまとめて表示され、それ以外は「月 水 金」のように並びます。

その下のチップは、**そのアラームがどう止まるか**を表しています。

| チップ | 意味 |
| --- | --- |
| **青の地点マーク**（例: 会社） | 止めるために行く場所（停止方法） |
| **緑の足あとマーク**（例: コンビニから歩行検知） | この場所に着くまで歩行検知が働かない設定です（→ [歩行検知を有効にする地点](#歩行検知を有効にする地点)） |
| **停止方法未設定** | 止める場所が決まっていません。鳴っても自動で止まらないので、編集して設定してください |

薄く表示されている行は、いまオフになっているアラームです。

### 操作

- **行をタップ** … 編集画面が開きます
- **右のスイッチ** … オン / オフの切り替え
- **右上の ＋** … 新しいアラームを追加（→ [はじめかた ③](/getting-started#_3-アラームを作る)）

### 編集画面

![アラームの編集画面](/screenshots/alarm-edit.png)

上から順に、**時刻**、**繰り返す曜日**、**停止方法**、**歩行検知を有効にする地点**を変えられます。
停止方法を選ぶと、その場所が地図で表示されます。

変更したら右上の **「保存」** を押してください。左上の矢印で戻ると変更は破棄されます。

一番下の **「このアラームを削除」** で削除できます。

::: warning 鳴っている間は変更・削除できません
鳴動中のアラームを開くと、その旨が表示されて操作できなくなります。
停止地点まで移動して止めてから操作してください。
:::

### 歩行検知を有効にする地点

アラームが鳴っている間、**歩いていると音が一時停止します**（→ [アラームが鳴ったら](/ringing#歩行中-静止中)）。
ただ、この歩行の検知はスマホの動きを見ているだけなので、
**布団の中でスマホを振っても「歩いている」ことにできてしまいます。**

「歩行検知を有効にする地点」は、そこを塞ぐための設定です。

設定すると、鳴り始めてから**その地点に着くまで、歩行の検知が働きません。**
それまでは、どれだけスマホを動かしても音は一時停止しません。
着いた時点で歩行の検知がオンになり、そこから停止地点までは歩いている間だけ音が止まります。

地点は、登録済みの**停止方法の中から**選びます。
使いたい場所がまだ無ければ、先に「停止」タブで登録してください。

::: tip 選ぶ場所
**ベッドから手の届かない場所**にしてください。枕元では意味がありません。
玄関やトイレなど、起き上がらないと行けない場所が向いています。
:::

設定しなくても構いません。その場合（「最初から有効」）は、鳴り始めた時点から歩行の検知が働きます。

::: info 止まる条件そのものは変わりません
この地点に着いても、**アラームは止まりません**。歩行の検知が始まるだけです。
**アラームが完全に止まるのは、停止方法の地点に着いたとき**です。
そのため、この地点と停止方法に**同じ場所は選べません**。
:::

## 停止

![停止方法の一覧](/screenshots/stop-methods.png)

**停止方法**（＝止めるために行く場所）を管理する画面です。

1行が1つの場所で、地図の小さなプレビュー、名前、到達判定の半径が出ます。
その下のチップは、**その場所を使っているアラームの時刻**です。
どのアラームにも使われていなければ「未使用」と出ます。

- **行をタップ** … 地図が大きく開きます。右下の **「編集」** から場所や半径、名前を変更できます
- **ゴミ箱アイコン** … 削除
- **右上の「追加」** … 新しい場所を登録（→ [はじめかた ②](/getting-started#_2-止める場所を登録する)）

![登録した場所を地図で確認する](/screenshots/stop-method-view.png)

### 使われている場所は削除できません

いずれかのアラームで使われている場所は、ゴミ箱が押せなくなります。
停止方法として使われている場合も、「歩行検知を有効にする地点」として使われている場合も同じです。

消してしまうと、そのアラームを止める手段が無くなってしまうためです。
どうしても消したいときは、先にそのアラームの設定を別の場所に変えてください。

::: info 鳴っているときは
アラームが鳴っている間、この画面は表示されません。
鳴り始めた瞬間に、画面全体が停止画面に切り替わります（→ [アラームが鳴ったら](/ringing)）。
:::

## 設定

![設定画面](/screenshots/settings.png)

**音を鳴らす機器とつなぐための画面**です。ふだんは触りません。

### 接続状態

一番上の図が、いまの接続状態を表しています。

```
[ アプリ ] ── [ ブローカー ] ── [ エッジ ]
```

**ブローカー**は、アプリと機器の間で連絡を中継する仕組みだと考えてください。
**エッジ**が音を鳴らす機器です。
線の下に「接続済み」「オンライン」と緑で出ていれば、正常につながっています。

その下の **「接続」「切断」** で、つなぐ・切るを切り替えます。

### ブローカー / エッジデバイス

入力する項目（URL、ユーザー名、パスワード、デバイスID）は、
**機器をお渡しするときにこちらからお伝えします。**
その値をそのまま入れて「接続」を押してください。自分で考える必要はありません。

::: tip つながっている間は書き換えられません
接続中に入力欄を触ると「接続中は設定を変更できません」と表示されます。
変更したいときは、先に **「切断」** を押してから書き換え、もう一度 **「接続」** してください。
:::

機器側の準備がまだのときは [機器のセットアップ](/device-setup) を先に済ませてください。

::: danger つながっていないとき
アラームの追加・変更ができず、一覧が暗く覆われます。
このときは [よくある質問](/faq#つながらない) を確認してください。
:::
