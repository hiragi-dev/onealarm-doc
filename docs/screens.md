# 画面の使い方

画面の下に3つのタブがあります。使う画面はこれだけです。

- 設定 … 音を鳴らす機器とつなぐ
- アラーム … 何時に鳴らすかを決める
- 停止 … どこまで歩けば止まるかを決める

## アラーム

![アラーム一覧](/screenshots/alarm-list.png)

登録したアラームが時刻順に並ぶ画面です。大きい数字が鳴る時刻で、その下に繰り返す曜日が出ます。曜日は「平日」「週末」「毎日」のようにまとめて表示され、それ以外の組み合わせは「月 水 金」のように並びます。

その下にあるチップは、そのアラームがどうやって止まるかを表しています。

- 青い地点マークのチップ(「会社」など) … 止めるために行く場所、つまり停止方法です
- 緑の足あとマークのチップ(「コンビニから歩行検知」など) … この場所に着くまで歩行検知が働かない設定になっています。詳しくは[後述](#walk-unlock-point)します
- 「停止方法未設定」 … 止める場所が決まっていません。このままだと鳴っても自動で止まらないので、編集して設定してください

薄く表示されている行は、いまオフになっているアラームです。

行をタップすると編集画面が開き、右のスイッチでオン/オフを切り替えられます。新しく追加するときは右上の＋からです([はじめかた ③](/getting-started#step-3)を参照)。

### 編集画面

![アラームの編集画面](/screenshots/alarm-edit.png)

上から順に、時刻、繰り返す曜日、停止方法、歩行検知を有効にする地点を変えられます。停止方法を選ぶとその場所が地図で出るので、どこだったか思い出せないときにも便利です。

変更したら右上の「保存」を押してください。左上の矢印で戻ると変更は破棄されます。削除するときは一番下の「このアラームを削除」からです。

注意点として、鳴っている最中のアラームは変更も削除もできません。開くとその旨が表示されて操作できなくなるので、停止地点まで移動して止めてから操作してください。

### 歩行検知を有効にする地点 {#walk-unlock-point}

アラームが鳴っている間は、歩いていると音が一時停止するようになっています([アラームが鳴ったら](/ringing#walking)を参照)。一度歩き出せばあとは停止地点まで持っていくだけで済むようにするための機能なのですが、この歩行検知はスマホの動きを見ているだけなので、布団の中でスマホを振っても「歩いている」ことにできてしまいます。

「歩行検知を有効にする地点」は、この抜け道を塞ぐための設定です。設定しておくと、鳴り始めてからその地点に着くまでは歩行検知が働かず、どれだけスマホを動かしても音は一時停止しません。着いた時点で歩行検知がオンになり、そこから停止地点までは歩いている間だけ音が止まる、という流れになります。

地点は登録済みの停止方法の中から選ぶので、使いたい場所がまだ無ければ先に「停止」タブで登録しておいてください。場所はベッドから手の届かないところ、玄関やトイレなど起き上がらないと行けない場所が向いています。枕元だと意味がないですね。

設定しなくても構いません。「最初から有効」のままにしておくと、鳴り始めた時点から歩行検知が働きます。

ちなみに、この地点に着いてもアラーム自体は止まりません。歩行検知が始まるだけで、アラームが完全に止まるのはあくまで停止方法の地点に着いたときです。そのため、この地点と停止方法に同じ場所を選ぶことはできないようになっています。

## 停止

![停止方法の一覧](/screenshots/stop-methods.png)

停止方法、つまり止めるために行く場所を管理する画面です。1行が1つの場所で、地図の小さなプレビュー、名前、到達判定の半径が並びます。その下のチップはその場所を使っているアラームの時刻で、どのアラームにも使われていなければ「未使用」と出ます。

行をタップすると地図が大きく開き、右下の「編集」から場所や半径、名前を変更できます。削除は右端のゴミ箱、新しい場所の登録は右上の「追加」からです(手順は[はじめかた ②](/getting-started#step-2)をご覧ください)。

![登録した場所を地図で確認する](/screenshots/stop-method-view.png)

(画像: 行をタップして地図を開いたところ)

### 使われている場所は削除できない

いずれかのアラームで使われている場所は、ゴミ箱が押せなくなっています。停止方法として使われている場合も、「歩行検知を有効にする地点」として使われている場合も同じです。
消してしまうとそのアラームを止める手段が無くなってしまうので、どうしても消したいときは先にそのアラームの設定を別の場所に変えてください。

また、アラームが鳴っている間はこの画面は表示されず、鳴り始めた瞬間に画面全体が停止画面に切り替わります。こちらは[アラームが鳴ったら](/ringing)で説明します。

## 設定 {#settings}

![設定画面](/screenshots/settings.png)

音を鳴らす機器とつなぐための画面で、ふだんは触りません。

### 接続状態

一番上の図が、いまの接続状態を表しています。

```
[ アプリ ] ── [ ブローカー ] ── [ エッジ ]
```

エッジが音を鳴らす機器で、ブローカーはアプリと機器の間で連絡を中継してくれるサーバーのようなものだと思ってください。線の下のチップが「接続済み」「オンライン」と緑で出ていれば正常につながっています。その下の「接続」「切断」で、つなぐ・切るを切り替えます。

### ブローカー / エッジデバイス

URL、ユーザー名、パスワード、デバイスIDを入力する欄です。ここに入れる値は機器をお渡しするときにこちらからお伝えするので、その値をそのまま入れて「接続」を押してください。自分で考える必要はありません。

つながっている間はこれらの欄が書き換えられないようになっていて、触ると「接続中は設定を変更できません」と出ます。変更したいときは先に「切断」を押してから書き換え、もう一度「接続」してください。

機器側の準備がまだのときは[機器のセットアップ](/device-setup)を先に済ませてください。また、つながっていない状態ではアラームの追加や変更ができず、一覧が暗く覆われます。そのときは[よくある質問](/faq#connection)をご覧ください。
