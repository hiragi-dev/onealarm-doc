# 機器の使い方

音を鳴らす機器の、ふだんの扱い方です。書き込みと初期設定は[機器のセットアップ](/device-setup)にあります。

## 置き場所と電源

アプリに停止地点として登録した場所に置きます。スマホがその停止地点に着くとアラームが止まる仕組みなので、登録した場所と機器の置き場所がずれていると、機器のそばに着いても止まりません。玄関や洗面所など、ベッドから起き上がって歩かないと行けない場所にしてください。手の届く所では意味がありません。

USB-C ケーブルで給電したままにしておきます。バッテリーだけでも動きますが、長くはもちません。給電が切れると内蔵バッテリーに切り替わり、鳴っている最中にケーブルを抜いても音は止まりません。

鳴っている間は、機器の電源ボタンをソフトウェアで無効にしています。押しても電源は切れません。ふだん電源を切るときの手順は[後述](#power-off)します。

## 画面の見方 {#screen}

通常の画面には上から順に次の情報が出ます。

- 現在時刻 … インターネットから合わせた時刻です。合うまでは time syncing... と出ます
- WiFi:OK MQTT:OK … WiFi とブローカーにつながっているかです。つながっていないと -- になります
- alarms:数 … 機器が持っているアラームの件数です。アプリで保存した数と同じになります
- next: 曜日 時刻 … 次に鳴る予定です
- hold BtnB:setup … 側面のボタンを長押しすると設定モードに入れる、という案内です

## ボタン

機器には3つのボタンがあります。

- 正面の大きいボタン … 確認画面で「はい」を答えるのに使います
- 側面のボタン … 3秒長押しで設定モードの確認画面を出します。確認画面では「いいえ」になります
- 電源ボタン … すばやく2回押すと電源を切る確認画面が出ます

どのボタンを押しても、アラームは止まりません。

## 鳴っているとき

設定した時刻になると、画面が赤くなって RINGING と表示され、1秒ごとにビープ音が鳴ります。アプリ側で音を一時停止している間は PAUSED と表示され、音だけが止まります。

鳴っている間は、機器のボタンは何も受け付けません。電源ボタンはソフトウェアで無効になり、設定モードにも入れません。電源ケーブルを抜いても内蔵バッテリーで鳴り続けます。

万一電源が落ちても、5分以内に電源が戻れば鳴り続けます。5分を過ぎていたときは鳴らさず、次の予定に回します。

30分鳴り続けた場合は、電源ボタンの制限だけが解除されます。機器が壊れて止められなくなるのを防ぐための保険で、アラームを止める手段ではありません。

## 電源の切り方 {#power-off}

1. 電源ボタンをすばやく2回押す
2. POWER OFF? と出るので、正面の大きいボタンを押す

側面のボタンを押すか10秒放置すると取りやめになります。アラームが鳴っている間は、この確認画面は出ません。

電源を入れるときは、電源ボタンを1回押します。

## 設定モード

WiFi やブローカーの設定を変えるときに使います。入り方と設定の内容は[機器のセットアップ](/device-setup#reset)にあります。

## うまくいかない場合

- 画面の WiFi や MQTT が -- になっている … [機器のセットアップ](/device-setup#troubleshoot)を見てください
- アプリで保存したアラームが alarms の数に反映されない … アプリの「設定」タブで接続状態を確認し、デバイスIDが機器の Device ID と同じか見てください
- 時刻がずれている … 時刻はインターネットから自動で合わせます。WiFi:OK になっているか確認してください

それでも直らないときは、[よくある質問](/faq#connection)も見てください。
