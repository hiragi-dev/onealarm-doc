# よくある質問

## 操作できないとき

「壊れた」ように見える場面のほとんどは、**わざとそうしている**制限です。

### アラームを変更・削除できない

**そのアラームがいま鳴っているためです。**

手元で設定を書き換えて止める、という抜け道を塞いでいます。
停止地点まで移動して止めてから操作してください。

### 停止方法が削除できない（ゴミ箱が押せない）

**いずれかのアラームで使われているためです。**「使用中」バッジが付いています。

消すと、そのアラームを止める手段が無くなってしまいます。
先に、そのアラームの停止方法を別のものに変更してください。

### 鳴っている最中に停止地点を変えられない

いま自分がいる場所へ停止地点をずらせば、歩かずに止められてしまうためです。

### ＋ボタンが押せず、アラームを追加できない

停止方法が1件も登録されていないためです。
先に「停止」タブで場所を登録してください（→ [はじめかた ②](/getting-started#_2-止める場所を登録する)）。

## つながらない

### 画面が暗く覆われて操作できない

音を鳴らす機器とつながっていない状態です。覆いの中に理由が書かれています。

| 表示 | 意味と対処 |
| --- | --- |
| **再接続しています…** | 自動で接続中です。数秒待ってください |
| **ブローカーに接続していません** | 「設定」タブで接続先を確認し、「接続」を押してください |
| **エッジデバイスがオフラインです** | 機器の**電源とネットワーク**を確認してください |

### 「接続できませんでした」と出る

- **ユーザー名とパスワードを確認してください** … 入力の間違いです
- **接続先と電波状況を確認してください** … アドレスの間違いか、通信環境の問題です

いずれもお渡しした値をそのまま入れ直すと直ることがほとんどです。

## 位置情報とセンサー

### なぜ位置情報が必要ですか

**停止地点に着いたかどうかを判定する**ためだけに使います。
歩行の検知（加速度センサー）も、歩いているかを表示するために使います。

どちらも**端末の中だけで処理し、外部に送信することはありません。**
移動の記録が保存されることもありません。

### 「位置情報の利用が拒否されています」と出る

一度断ってしまうと、アプリからは聞き直せません。
**端末側の設定**から、このアプリ（またはブラウザ）に位置情報を許可してください。

### 位置情報や歩行検知に対応していないと出る

古い端末やブラウザでは使えないことがあります。
また、**HTTPSでの接続が必要**です。

## その他

### 設定が消えてしまいました

ブラウザのタブのまま使っていた可能性が高いです。
**7日間ほど使わないと、ブラウザが自動でデータを消してしまうこと**があります。

[ホーム画面に追加](/getting-started#_1-ホーム画面に追加する) してから使い直してください。
なお、追加してもそれまでの設定は引き継がれないため、**作り直しになります。**

### スマホの電源を切ったら止まりますか

止まりません。**鳴らしているのはスマホではなく別の機器**です。
スマホを機内モードにしても、電源を切っても、音は鳴り続けます。

### 機器のそばに戻れば止められますか

止められません。機器側にも停止ボタンはありません。
**停止地点まで移動する以外の方法はありません。**

### 対応している端末は

- iPhone / iPad（Safari など）
- Android（Chrome など）
- パソコン（Chrome、Edge、Safari など）

初回起動時に、位置情報と歩行検知の許可を求められます。どちらも許可してください。

### アラームは複数登録できますか

できます。平日用・休日用のように分けられ、それぞれ別の停止方法を割り当てられます。
