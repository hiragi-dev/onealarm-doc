# よくある質問

## 操作できない場合

壊れたように見える場面のほとんどは、意図した制限です。

### アラームを変更・削除できない場合

そのアラームが鳴っているためです。手元で設定を書き換えて止める、という抜け道を塞いでいます。停止地点まで移動して止めてから操作してください。

### 停止方法を削除できない場合

いずれかのアラームで使われているためです。行の下に、使っているアラームの時刻がチップで出ています。消すと、そのアラームを止める手段が無くなります。先にそのアラームの停止方法を別のものに変更してください。

歩行検知を有効にする地点として使われている場合も同じです。そちらはアラームの編集画面で、「最初から有効」か別の地点に変えてください。

### 鳴動中に停止地点を変えられない場合

今いる場所へ停止地点をずらせば、歩かずに止められてしまうためです。

### ＋ボタンが押せない場合

停止方法が1件も登録されていないためです。先に「停止」タブで場所を登録してください。登録の流れは[はじめかた](/getting-started#stop-method)のとおりです。

### 「停止方法と別の地点を選んでください」の表示

「歩行検知を有効にする地点」に、停止方法と同じ場所を選んでいます。停止方法の地点に着いた時点でアラーム自体が止まるので、同じ場所では意味がありません。別の場所を選ぶか、「最初から有効」にしてください。

### 設定タブの入力欄を書き換えられない場合

機器につながっている間は変更できません。先に「切断」を押してから書き換え、もう一度「接続」してください。

## 接続できない場合 {#connection}

### 画面が暗く覆われる場合

音を鳴らす機器とつながっていない状態です。覆いの中に理由が書かれています。

- 「再接続しています…」 … 自動で接続中です。数秒待ってください
- 「ブローカーに接続していません」 … 「設定」タブで接続先を確認し、「接続」を押してください
- 「エッジデバイスがオフラインです」 … 機器の画面が WiFi:OK MQTT:OK になっているか、アプリのデバイスIDが機器の Device ID と同じかを確認してください

### 「接続できませんでした」の表示

メッセージの続きで原因が分かります。

- 「ユーザー名とパスワードを確認してください」 … 入力の間違いです
- 「接続先と電波状況を確認してください」 … アドレスの間違いか、通信環境の問題です

どちらの場合も、配布時に案内した値をそのまま入れ直すと直ることがほとんどです。

## 位置情報とセンサー

### 位置情報が必要な理由

停止地点に着いたかどうかを判定するためだけに使います。歩行検知は加速度センサーを使っていて、歩いているかの表示と、歩いている間だけ音を一時停止するために使います。

どちらも端末の中だけで処理し、外部には送信しません。移動の記録も保存しません。

### 「位置情報の利用が拒否されています」の表示

一度断ってしまうと、アプリからは聞き直せません。端末側の設定から、このアプリやブラウザに位置情報を許可してください。

### 位置情報・歩行検知に非対応と表示される場合

古い端末やブラウザでは使えないことがあります。HTTPSでの接続も必要です。

## その他

### 設定が消えた場合

ブラウザのタブのまま使っていた可能性が高いです。7日間ほど使わないと、ブラウザが自動でデータを消してしまうことがあります。[ホーム画面に追加](/getting-started#install)してから使い直してください。追加してもそれまでの設定は引き継がれないので、作り直しになります。

### スマホの電源を切った場合

止まりません。鳴らしているのはスマホではなく別の機器です。機内モードにしても、電源を切っても、音は鳴り続けます。

### 機器のそばに戻った場合

止められません。機器のボタンを押しても、電源ボタンを押しても止まりません。停止地点まで移動する以外の方法はありません。

### 機器のケーブルを抜いた場合

止まりません。機器にはバッテリーが入っていて、給電が切れてもそのまま鳴り続けます。

### 機器の電源が切れない場合

電源ボタンを1回押しただけでは切れないようにしてあります。電源ボタンをすばやく2回押すと確認画面が出るので、正面の大きいボタンで承認してください。アラームが鳴っている間は、この確認画面も出ません。詳しくは[機器の使い方](/device#power-off)を見てください。

### WiFi を変えた場合

機器を設定モードに入れて、新しい WiFi を選び直します。手順は[機器のセットアップ](/device-setup#reset)にあります。

### 布団の中でスマホを振った場合

「歩行検知を有効にする地点」を設定しておけば、歩いたことにはなりません。

歩いている間は音が一時停止しますが、この地点を設定したアラームでは、そこに着くまで歩行検知そのものが始まりません。玄関など、ベッドから離れた場所を選んでおけば、寝たまま振っても音は止まりません。詳しくは[画面の使い方](/screens#walk-unlock-point)で説明しています。

どちらの設定でも、アラームが完全に止まるのは停止地点に着いたときだけです。

### 対応している端末

- iPhone / iPad の Safari など
- Android の Chrome など
- パソコンの Chrome、Edge、Safari など

初回起動時に位置情報と歩行検知の許可を求められます。どちらも許可してください。

### アラームの複数登録

できます。平日用と休日用のように分けて、それぞれ別の停止方法を割り当てられます。
