# よくある質問

## 操作できない場合

壊れたように見える場面のほとんどは、意図した制限である。

### アラームを変更・削除できない場合

そのアラームが鳴っているため。手元で設定を書き換えて止める、という抜け道を塞いでいるので、停止地点まで移動して止めてから操作する。

### 停止方法を削除できない場合

いずれかのアラームで使われているため。行の下に、使っているアラームの時刻がチップで出ている。
消すとそのアラームを止める手段が無くなるため、先にそのアラームの停止方法を別のものに変更する。

歩行検知を有効にする地点として使われている場合も同じ。そちらはアラームの編集画面で「最初から有効」か別の地点に変える。

### 鳴動中に停止地点を変えられない場合

今いる場所へ停止地点をずらせば、歩かずに止められてしまうため。

### ＋ボタンが押せない場合

停止方法が1件も登録されていないため。先に「停止」タブで場所を登録する。手順は[はじめかた](/getting-started#step-2)に書いている。

### 「停止方法と別の地点を選んでください」の表示

「歩行検知を有効にする地点」に、停止方法と同じ場所を選んでいる。停止方法の地点に着いた時点でアラーム自体が止まるため、同じ場所では意味がない。別の場所を選ぶか、「最初から有効」にする。

### 設定タブの入力欄を書き換えられない場合

機器につながっている間は変更できない。先に「切断」を押してから書き換え、もう一度「接続」する。

## 接続できない場合 {#connection}

### 画面が暗く覆われる場合

音を鳴らす機器とつながっていない状態。覆いの中に理由が書かれている。

- 「再接続しています…」 … 自動で接続中。数秒待つ
- 「ブローカーに接続していません」 … 「設定」タブで接続先を確認し、「接続」を押す
- 「エッジデバイスがオフラインです」 … 機器の電源とネットワークを確認する

### 「接続できませんでした」の表示

メッセージの続きで原因が分かる。

- 「ユーザー名とパスワードを確認してください」 … 入力の間違い
- 「接続先と電波状況を確認してください」 … アドレスの間違いか、通信環境の問題

いずれも、配布時に案内した値をそのまま入れ直すと直ることがほとんど。

## 位置情報とセンサー

### 位置情報が必要な理由

停止地点に着いたかどうかを判定するためだけに使う。歩行検知は加速度センサーを使い、歩いているかを表示することと、歩いている間だけ音を一時停止するために使う。

どちらも端末の中だけで処理し、外部には送信しない。移動の記録が保存されることもない。

### 「位置情報の利用が拒否されています」の表示

一度断ってしまうと、アプリからは聞き直せない。端末側の設定から、このアプリやブラウザに位置情報を許可する。

### 位置情報・歩行検知に非対応と表示される場合

古い端末やブラウザでは使えないことがある。また、HTTPSでの接続が必要。

## その他

### 設定が消えた場合

ブラウザのタブのまま使っていた可能性が高い。7日間ほど使わないと、ブラウザが自動でデータを消してしまうことがある。
[ホーム画面に追加](/getting-started#step-1)してから使い直す。追加してもそれまでの設定は引き継がれないため、作り直しになる。

### スマホの電源を切った場合

止まらない。鳴らしているのはスマホではなく別の機器なので、スマホを機内モードにしても電源を切っても音は鳴り続ける。

### 機器のそばに戻った場合

止められない。機器側にも停止ボタンはなく、停止地点まで移動する以外の方法はない。

### 布団の中でスマホを振った場合

「歩行検知を有効にする地点」を設定しておけば、歩いたことにはならない。

歩いている間は音が一時停止するが、この地点を設定したアラームではそこに着くまで歩行検知そのものが始まらない。玄関など、ベッドから離れた場所を選んでおけば、寝たまま振っても音は止まらない。詳しくは[画面の使い方](/screens#walk-unlock-point)を参照。

なお、どちらの設定でもアラームが完全に止まるのは停止地点に着いたときだけである。

### 対応している端末

- iPhone / iPad の Safari など
- Android の Chrome など
- パソコンの Chrome、Edge、Safari など

初回起動時に位置情報と歩行検知の許可を求められるので、どちらも許可する。

### アラームの複数登録

できる。平日用と休日用のように分けて、それぞれ別の停止方法を割り当てられる。

---

なお、このアプリはまだ開発中である。表示されるアラームや現在地はサンプルデータで、実際の機器とはまだ接続していない。ここに書いた内容も今後変わることがある。
