# はじめかた

最初にやることは3つあります。順番を飛ばすと設定を作り直すことになる場合があるため、上から順に進めてください。

## ① ホーム画面への追加 {#step-1}

最初に必ずこれを行います。
ブラウザのタブで開いたまま使っていると、しばらく使わない間にアラームの設定が消えてしまうことがあります。しかも、後からホーム画面に追加してもそれまでの設定は引き継がれないため、設定を作ってから追加すると、作った設定が無駄になります。

- iPhone / iPad … 画面下の共有ボタンをタップし、メニューから「ホーム画面に追加」を選びます
- Android / パソコン … 画面下に出てくる案内の「インストール」を押し、確認のダイアログでもう一度「インストール」を選びます

追加が終わったら、以降はホーム画面のアイコンから開きます。

## ② 止める場所の登録 {#step-2}

次に、どこまで歩いたらアラームが止まるかを決めます。アプリではこれを停止方法と呼びます。

<PhoneShot src="/screenshots/stop-methods.png" alt="停止方法の一覧" />

1. 画面下の「停止」タブを開く
2. 右上の「追加」を押す
3. 地図が開くので、止めたい場所をタップする
4. 画面下のスライダーで半径を決める
5. 「次へ」を押し、洗面所やコンビニなどの名前を入れて「保存」

<PhoneShot src="/screenshots/stop-method-map.png" alt="地図で地点と半径を選ぶ" />

半径は、この円の中に入ったら到着したとみなす範囲です。地図右上のボタンを押すと今いる場所に地図が移動します。名前は20文字までです。

### 半径の目安 {#radius}

5mから200mまで選べますが、15mから50mが目安です。
狭すぎると位置情報の誤差で到着したと判定されず、いつまでも止まりません。広すぎると家から出ないうちに止まってしまい、意味がなくなります。建物の中はGPSが弱くなるため、建物の入口あたりを選ぶと確実です。

### 場所の選び方

必ず靴を履いて外に出る場所、たとえば玄関の外や集合ポスト、コンビニなどにするほど効果があります。家の中の洗面所などでも、ベッドから距離があれば効果はあります。
ただし遠すぎるとかえって起きられなくなるため、片道1分から3分の場所から試すとよいです。

## ③ アラームの作成 {#step-3}

停止方法を1つ以上登録すると、アラームが作れるようになります。

<PhoneShot src="/screenshots/alarm-list.png" alt="アラーム一覧" />

「アラーム」タブの右上の＋を押すと、4つの質問に順番に答える画面が開きます。

1. 鳴らす時刻
2. 鳴らす曜日
3. 止める場所
4. 内容の確認

曜日は1つ以上選びます。止める場所は、②で登録した停止方法の中から1つ選びます。

<PhoneShot src="/screenshots/alarm-wizard-time.png" alt="時刻を決める" />

3つ目のステップでは、選んだ場所が地図で表示されます。寝起きに本当にそこまで歩けるかをここで確認しておいてください。

<PhoneShot src="/screenshots/alarm-wizard-stop-method.png" alt="停止方法を選ぶ" />

最後の確認画面には「歩行検知を有効にする地点」という項目もありますが、最初は「最初から有効」のままで構いません。何のための設定かは[画面の使い方](/screens#walk-unlock-point)に書いています。

<PhoneShot src="/screenshots/alarm-wizard-confirm.png" alt="内容を確認して保存する" />

「保存」を押すと一覧に追加され、設定は完了です。

なお、停止方法がまだ1件も無いと＋ボタンは押せません。押せないときは先に②を済ませてください。
