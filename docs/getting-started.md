# はじめかた

最初にやることは3つです。順番に意味があるので、上から順に進めてください(飛ばすと設定を作り直すことになる場合があります)。

## ① ホーム画面に追加する {#step-1}

いちばん最初にやっていただきたいのがこれです。
ブラウザのタブで開いたまま使っていると、しばらく使わない間にアラームの設定が消えてしまうことがあります。しかも、後からホーム画面に追加してもそれまでの設定は引き継がれないので、「設定を作ってから追加する」と作った設定が無駄になってしまいます。

- iPhone / iPad … 画面下の共有ボタン(□に↑のマーク)をタップして、メニューから「ホーム画面に追加」を選びます
- Android / パソコン … 画面下に出てくる案内の「インストール」を押して、確認のダイアログでもう一度「インストール」を選びます

追加が終わったら、以降はホーム画面のアイコンから開いてください。

## ② 止める場所を登録する {#step-2}

次に、「どこまで歩いたらアラームが止まるか」を決めます。アプリではこれを停止方法と呼んでいます。

![停止方法の一覧](/screenshots/stop-methods.png)

(画像: 停止方法の一覧)

1. 画面下の「停止」タブを開く
2. 右上の「追加」を押す
3. 地図が開くので、止めたい場所をタップする
4. 画面下のスライダーで半径を決める(この円の中に入ると「着いた」と判定されます)
5. 「次へ」を押して名前(洗面所、コンビニ、最寄り駅など)を入れ、「保存」

![地図で地点と半径を選ぶ](/screenshots/stop-method-map.png)

(画像: 地図で地点と半径を選んでいるところ)

地図右上のボタンを押すと今いる場所に移動できます。名前は20文字までです。

### 半径はどのくらいがいいか {#radius}

15~50mくらいが目安だと思います(5~200mの範囲で選べます)。
狭すぎると位置情報の誤差で到着したと判定されずいつまでも止まりませんし、広すぎると家から出ないうちに止まってしまって意味がなくなります。建物の中はGPSが弱くなるので、建物の入口あたりを選んでおくと確実ですね。

### どんな場所を選ぶといいか

必ず靴を履いて外に出る場所(玄関の外、集合ポスト、コンビニなど)ほど効果があります。家の中の洗面所などでも、ベッドから距離があればそれなりに効きます。
ただ、遠すぎると寝坊が悪化するだけなので、片道1~3分くらいから試してみるのがおすすめです。

## ③ アラームを作る {#step-3}

停止方法を1つ以上登録すると、アラームが作れるようになります。

![アラーム一覧](/screenshots/alarm-list.png)

「アラーム」タブの右上の＋を押すと、4つの質問に順番に答える画面が開きます。

1. 何時に鳴らすか
2. どの曜日に鳴らすか(1つ以上)
3. どこまで行けば止まるか(②で作った停止方法から1つ選びます)
4. 内容の確認

![時刻を決める](/screenshots/alarm-wizard-time.png)

3つ目のステップでは、選んだ場所が地図で表示されます。寝起きに本当にそこまで歩けるかをここで確認しておいてください。

![停止方法を選ぶ](/screenshots/alarm-wizard-stop-method.png)

最後の確認画面には「歩行検知を有効にする地点」という項目もあるのですが、最初は「最初から有効」のままで大丈夫です。何のための設定かは[画面の使い方](/screens#walk-unlock-point)に書いています。

![内容を確認して保存する](/screenshots/alarm-wizard-confirm.png)

「保存」を押すと一覧に追加されて、設定は完了です。

ちなみに、停止方法がまだ1件も無いと＋ボタンが押せないようになっています。押せないときは先に②を済ませてください。
