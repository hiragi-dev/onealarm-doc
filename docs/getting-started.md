# はじめかた

最初にやることは3つだけです。上から順に進めてください。

::: tip 順番が大事です
**①ホーム画面に追加 → ②止める場所を登録 → ③アラームを作る** の順で進めてください。
順番を飛ばすと、設定がやり直しになることがあります。
:::

## ① ホーム画面に追加する

**いちばん最初にやってください。**

ブラウザのタブで開いたまま使うと、**しばらく使わない間にアラームの設定が消えてしまうこと**があります。
しかも、あとからホーム画面に追加しても、それまでの設定は引き継がれません。
つまり「設定を作ったあとに追加する」と、作った設定が無駄になります。

::: code-group

```[iPhone / iPad]
1. 画面下の「共有」ボタン（□に↑のマーク）をタップ
2. メニューの中から「ホーム画面に追加」を選ぶ
```

```[Android / パソコン]
1. 画面下に出てくる案内の「インストール」ボタンを押す
2. 確認のダイアログで「インストール」を選ぶ
```

:::

追加が終わったら、**ホーム画面のアイコンから開き直して**ください。以降はそちらを使います。

## ② 止める場所を登録する

「どこまで歩いたらアラームを止めるか」を先に決めます。これを **停止方法** と呼びます。

![停止方法の一覧](/screenshots/stop-methods.png)

1. 画面下の **「停止」** タブを開く
2. 右上の **「追加」** を押す
3. 地図が開くので、**止めたい場所をタップ**する
4. 画面下のスライダーで **半径** を決める（この円の中に入れば「到着した」と判定されます）
5. **「次へ」** を押し、**名前**（例: 洗面所、コンビニ、最寄り駅）を入れて **「保存」**

![地図で地点と半径を選ぶ](/screenshots/stop-method-map.png)

地図の右上のボタンを押すと、今いる場所まで地図が移動します。
名前は20文字までです。

### 半径はどのくらいがいいですか

**15〜50メートル**くらいが目安です（5〜200メートルの範囲で選べます）。

- **狭すぎる**（5m など）と、位置情報の誤差で到着したと判定されず、いつまでも止まりません
- **広すぎる**（200m など）と、家から出ないうちに止まってしまい、意味がなくなります

建物の中に入るとGPSが弱くなるので、**建物の入口あたり**を選ぶと確実です。

### どんな場所を選ぶといいですか

- **必ず靴を履いて外に出る場所**（玄関の外・集合ポスト・コンビニ）ほど効果があります
- 家の中の洗面所などでも、ベッドから距離があれば効果はあります
- 遠すぎると寝坊が悪化します。**片道1〜3分**くらいから試すのがおすすめです

## ③ アラームを作る

停止方法を1つ以上登録すると、アラームが作れるようになります。

![アラーム一覧](/screenshots/alarm-list.png)

1. **「アラーム」** タブの右上 **＋** を押す
2. 4つの質問に順番に答えます

| ステップ | 決めること |
| --- | --- |
| STEP 1 | **何時に鳴らすか** |
| STEP 2 | **どの曜日に鳴らすか**（1つ以上） |
| STEP 3 | **どこまで行けば止まるか**（②で作った停止方法から1つ） |
| STEP 4 | 内容の確認 → **「保存」** |

![時刻を決める](/screenshots/alarm-wizard-time.png)

STEP 3 では、選んだ場所が地図で表示されます。**本当にそこまで歩けるか**をここで確認してください。

![停止方法を選ぶ](/screenshots/alarm-wizard-stop-method.png)

STEP 4 には **「歩行検知を有効にする地点」** という項目もありますが、最初は
**「最初から有効」のままで構いません**。何のための設定かは
[画面の使い方](/screens#歩行検知を有効にする地点) に書いてあります。

![内容を確認して保存する](/screenshots/alarm-wizard-confirm.png)

保存すると一覧に追加され、設定は完了です。

::: warning ＋ボタンが押せないとき
停止方法がまだ1件も登録されていないと、アラームは作れません。
先に **②** を済ませてください。
:::
