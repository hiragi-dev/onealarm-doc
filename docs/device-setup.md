# 機器のセットアップ

音を鳴らす側の機器を使えるようにする手順です。機器には M5StickS3 という手のひらサイズの端末を使います。本体にスピーカーと画面とバッテリーが入っていて、WiFi にもつながります。専用のプログラムを書き込むと OneAlarm の機器になります。以下ではこのプログラムをファームウェアと呼びます。

機器とアプリは、まだ実際につないで確認できていません。ここに書いた手順や設定値は今後変わることがあります。

## 用意するもの

- M5StickS3 … 音を鳴らす本体です
- USB-C ケーブル … 書き込みと電源に使います。充電専用ではなく、データ通信できるものが必要です
- パソコン … ファームウェアの書き込みに1回だけ使います
- スマートフォン … 初期設定の画面を開くのに使います。アプリを入れたもので構いません
- 自宅の WiFi … 2.4GHz のものが必要です。5GHz 専用の WiFi にはつなげません
- ファームウェアのファイル … `onealarm_v1.0.0_merged.bin` という名前のファイルです。配布時に渡します
- ブローカーの接続情報 … アドレス、ユーザー名、パスワードの3つです。配布時に案内します

## ① ファームウェアの書き込み

M5Stack 公式の書き込みツール M5Burner を使います。

1. パソコンに M5Burner を入れる。配布元は https://docs.m5stack.com/en/download です
2. 機器を USB-C ケーブルでパソコンにつなぐ
3. M5Burner の「User Custom」を開き、ファームウェアのファイルを選ぶ
4. 書き込み先のアドレスを 0x0 にして書き込む

M5Burner の画面の名前や配置はバージョンで変わることがあります。esptool が使える環境なら、次のコマンドでも書き込めます。

```sh
esptool.py --chip esp32s3 write_flash 0x0 onealarm_v1.0.0_merged.bin
```

書き込みが終わると機器が再起動し、青い画面に SETUP MODE と表示されます。ファームウェアには WiFi やブローカーの情報が入っていないので、初回は必ずこの画面から始まります。

## ② 初期設定

SETUP MODE の間、機器は自分自身が WiFi の親機になっています。スマホからそこにつないで、設定画面を開きます。

1. スマホの WiFi 設定で「OneAlarm-Setup」を選ぶ。パスワードは onealarm です
2. ブラウザで http://192.168.4.1 を開く。つないだ直後に設定画面が自動で開くこともあります
3. 「Configure WiFi」を押し、一覧から自宅の WiFi を選んでパスワードを入れる
4. 同じ画面にある次の項目を入れる
5. 保存する。機器が再起動し、通常の画面になります

4で入れる項目は以下です。

- MQTT Host … ブローカーのアドレスです。配布時に案内します
- MQTT Port … 8883 のまま変えません
- MQTT User … ブローカーのユーザー名です。配布時に案内します
- MQTT Password … ブローカーのパスワードです。配布時に案内します
- Device ID … この機器の名前です。好きな英数字で構いません。空のままだと sticks3 になります

Device ID は、あとでアプリの「設定」タブに入れるデバイスIDと同じ値にします。

## ③ 動作確認

再起動後の画面に、時刻と WiFi:OK MQTT:OK が出ていれば準備完了です。時刻が出るまでは time syncing... と表示されます。数十秒待っても変わらないときは、後述の「うまくいかない場合」を見てください。画面の各行の意味は[機器の使い方](/device#screen)で説明しています。

続けてアプリ側を設定します。手順は[はじめかた](/getting-started#connect)にあります。

## アプリの設定値との対応

アプリの「設定」タブに入れる値と、②で機器に入れた値は次のように対応します。

- アプリの URL … ブローカーの WebSocket 用アドレスで、wss://ホスト名:8884/mqtt の形です。機器の MQTT Host にはこのホスト名の部分だけを入れます
- アプリのユーザー名 … 機器の MQTT User と同じ値です
- アプリのパスワード … 機器の MQTT Password と同じ値です
- アプリのデバイスID … 機器の Device ID と同じ値です

## 設定のやり直し {#reset}

WiFi を変えたときや、ブローカーの情報を入れ間違えたときは、もう一度 SETUP MODE に入ります。入り方は2通りあります。

- 電源を入れるとき、正面の大きいボタンを押したまま2秒ほど待つ
- 通常の画面で、側面のボタンを3秒長押しする。SETUP MODE? と確認が出るので、正面の大きいボタンで承認する。側面のボタンを押すか10秒放置すると取りやめになります

アラームが鳴っている間は、どちらの方法でも SETUP MODE に入れません。

設定画面の MQTT Password は空欄のままにすると前の値が残ります。パスワードを変えないときは入れ直す必要はありません。

## うまくいかない場合 {#troubleshoot}

- WiFi:-- のまま … 自宅の WiFi が 2.4GHz か、パスワードが合っているかを確認して、設定をやり直します
- MQTT:-- のまま … MQTT Host、MQTT User、MQTT Password を確認して、設定をやり直します。MQTT Port が 8883 になっているかも見てください
- time syncing... のまま … 機器がインターネットに出られていません。WiFi:OK になっているか確認してください
- アプリに「エッジデバイスがオフラインです」と出る … 機器の画面が MQTT:OK になっているか、アプリのデバイスIDが機器の Device ID と同じかを確認してください
- 書き込みが始まらない … USB-C ケーブルがデータ通信できるものか確認してください。充電専用のケーブルでは書き込めません

それでも直らないときは、[よくある質問](/faq#connection)も見てください。
