## OneAlarm とは

朝アラームを止めてそのまま二度寝してしまう、というのを意志の力ではなく仕組みで防ぐためのアラーム。

ふつうのアラームが止められてしまうのは、止めるものが枕元にあるからだ。OneAlarm では、音を鳴らすのはスマホではなく、別の部屋などに置いた専用の機器になっている。アプリからこの機器を止めることはできず、あらかじめ登録しておいた場所まで実際に歩いて行くと自動的に鳴り止む、というのが基本の仕組みである。

場所は洗面所でも玄関でもコンビニでも構わない。着くまでは鳴り続けるが、歩いている間は音が一時停止するため、移動中ずっと鳴りっぱなしになることはない。立ち止まるとまた鳴り始める。

なお、現在はまだ開発中で、音を鳴らす機器とはつながっていない。アプリに表示されるアラームや現在地はすべて動作確認用のサンプルである。

## 使うために必要なもの

- スマートフォンまたはパソコン … iPhone でも Android でも使える
- 音を鳴らす機器 … 別途用意する。設定方法は配布時に案内する
- 位置情報と歩行検知の許可 … 初回起動時に求められる

位置情報は停止地点に着いたかどうかの判定に使う。歩行検知は加速度センサーを使い、歩いている間に音を一時停止するために使う。どちらも端末の中だけで処理し、外部には送らない。
