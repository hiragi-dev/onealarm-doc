## OneAlarm とは

朝アラームを止めて、そのまま二度寝してしまう。OneAlarm は、これを意志の力ではなく仕組みで防ぐためのアラームです。

ふつうのアラームが止められてしまうのは、止めるものが枕元にあるからです。そこで OneAlarm では、音を鳴らす役目をスマホではなく、別の部屋などに置いた専用の機器に持たせています。アプリからこの機器は止められません。止める方法は一つだけです。あらかじめ登録しておいた場所まで実際に歩いて行くと、自動的に鳴り止みます。

場所は洗面所でも玄関でもコンビニでも構いません。着くまでは鳴り続けます。ただ、歩いている間は音が一時停止するので、移動中ずっと鳴りっぱなしになることはありません。立ち止まるとまた鳴り始めます。

現在はまだ開発中で、音を鳴らす機器とはつながっていません。アプリに表示されるアラームや現在地は、すべて動作確認用のサンプルです。

## 使うために必要なもの

- スマートフォンまたはパソコン … iPhone でも Android でも使えます
- 音を鳴らす機器 … 別途用意します。設定方法は配布時に案内します
- 位置情報と歩行検知の許可 … 初回起動時に求められます

位置情報は、停止地点に着いたかどうかの判定にだけ使います。歩行検知は加速度センサーを使っていて、歩いている間に音を一時停止するためのものです。どちらも端末の中だけで処理し、外部には送りません。
