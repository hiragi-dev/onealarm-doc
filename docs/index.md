## OneAlarm とは

朝アラームを止めて、そのまま二度寝してしまう。OneAlarm は、これを意志の力ではなく仕組みで防ぐためのアラームです。

OneAlarm では、鳴っている機器のところまで実際に歩いていかないと、アラームは絶対に止まりません。音を鳴らすのはスマホではなく、玄関や洗面所など起き上がらないと行けない場所に置いた専用の機器です。機器は M5StickS3 という手のひらサイズの端末で、スピーカーと画面とバッテリーを内蔵しています。機器を置いた場所をアプリに停止地点として登録しておくと、そこまで歩いて着いたときだけ、自動的に鳴り止みます。

止める方法はこれだけです。次のどれをしても止まりません。

- アプリの操作 … 停止ボタンはありません。鳴っている間はアラームの変更も削除もできません
- スマホの電源を切る … 鳴らしているのはスマホではないので、音は続きます
- 機器のボタンを押す … どのボタンを押しても止まりません。電源ボタンも鳴っている間は効きません
- 機器のケーブルを抜く … バッテリーで鳴り続けます

着くまでは鳴り続けますが、歩いている間は音が一時停止するので、移動中ずっと鳴りっぱなしになることはありません。立ち止まるとまた鳴り始めます。

現在はまだ開発中で、アプリと機器はまだ実際につないで確認できていません。アプリに表示されるアラームや現在地は、すべて動作確認用のサンプルです。

## 使うために必要なもの

- スマートフォンまたはパソコン … アプリを動かします。iPhone でも Android でも使えます
- M5StickS3 と USB-C ケーブル … 音を鳴らす機器です。歩いて行く先に置きます。プログラムは配布時に渡します
- 自宅の WiFi … 機器がインターネットに出るのに使います。2.4GHz のものが必要です
- ブローカーの接続情報 … アプリと機器の間で連絡を中継するサーバーの情報です。配布時に案内します
- 位置情報と歩行検知の許可 … アプリの初回起動時に求められます

位置情報は、停止地点に着いたかどうかの判定にだけ使います。歩行検知は加速度センサーを使っていて、歩いている間に音を一時停止するためのものです。どちらも端末の中だけで処理し、外部には送りません。
