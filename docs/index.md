## OneAlarm とは

**朝、アラームを止めてまた寝てしまう**——これを、意志ではなく仕組みで防ぐためのアプリです。

ふつうのアラームは、枕元のスマホで止められます。だから止まります。そして二度寝します。

OneAlarm では、音を鳴らすのはスマホではなく、**別の部屋などに置いた専用の機器**です。
そしてアプリからその機器を止めることはできません。
止める方法はひとつだけ、**あらかじめ登録しておいた場所まで、実際に歩いて行くこと**です。

洗面所でも、玄関でも、コンビニでも構いません。
そこに着いた瞬間、アラームは自動的に鳴り止みます。着くまでは鳴り続けます。

::: warning 現在は開発中です
画面はひととおり動きますが、まだ音を鳴らす機器とは接続していません。
アプリに表示されるアラームや現在地は、すべて動作確認用のサンプルです。
:::

## 使うために必要なもの

- **スマートフォン**（iPhone / Android）またはパソコン
- **音を鳴らす機器**（別途用意します。設定方法は配布時にお伝えします）
- **位置情報と歩行の検知の許可** — 到着したかどうかの判定に使います。
  どちらも端末の中だけで処理し、外部へ送ることはありません。
